## 下午（1.5~2h）：路径参数 + 查询参数

### 3. Path Parameters（45min）

📖 文档：https://fastapi.tiangolo.com/zh/tutorial/path-params/

边读边敲，重点掌握：

- [ ] 带类型声明的路径参数：`/items/{item_id}`（int 类型自动校验）
- [ ] 故意传一个字符串（如 `/items/foo`），**观察 422 错误响应长什么样**——理解 Pydantic 校验的价值
- [ ] 路径顺序陷阱：`/users/me` 和 `/users/{user_id}` 的先后问题（官方文档有讲，必须亲手复现一次）
- [ ] 枚举参数：用 `Enum` 限制可选值（如 `/models/{model_name}`）

### 4. Query Parameters（45min）

📖 文档：https://fastapi.tiangolo.com/zh/tutorial/query-params/

- [ ] 默认查询参数：`/items/?skip=0&limit=10`
- [ ] 可选参数：`q: str | None = None`
- [ ] 类型转换：`short: bool = False`，测试 `?short=1`、`?short=true` 的效果
- [ ] 必传查询参数（不给默认值）

✅ 验收标准（合上书做）：

> 不看任何文档，写一个接口 `GET /users/{user_id}/items/`：
> - 路径参数 `user_id: int`
> - 查询参数 `keyword: str | None = None`，`page: int = 1`
> - 返回 JSON 包含全部参数
>
> 能 15 分钟内写出来并跑通 = 今日目标达成。

## 防坑提醒

1. **不要在虚拟环境之外装包**——每次打开终端先 `source .venv/Scripts/activate`
2. Windows 下 `fastapi dev` 如果报编码错误，在文件开头加 `# -*- coding: utf-8 -*-` 并用 `uvicorn main:app --reload` 启动
3. 官方文档全程 **1.0 倍速动手敲**，不要复制粘贴——敲错报错的印象比读十遍深
4. 今天内容不难，如果提前完成，**不要提前学 Request Body**（明天的任务），把时间加给算法题
